
# Ejercicios_java_ProgramacionI
=============================

## Descripción breve
-----------------
Dentro de `src/` encontrarás varios proyectos pequeños. Cada proyecto sigue una estructura por paquetes/carpetas similar a:

- `app/` — contiene la clase con el método `main` (punto de entrada del proyecto).
- `domain/` — entidades y modelos del dominio.
- `services/` — lógica/servicios de negocio.

### Cómo compilar y ejecutar (resumen)
--------------------------------
1. Para ejecutar un proyecto, buca la clase `app` del proyecto que quieras correr. Ejemplo (si el proyecto se llama `Estudiantes` y la clase principal es `App` en el paquete `Estudiantes.app`), le das run solo a esa clase.
